Patch 4/5: b43: N-PHY: use wl's delays in the 2057 RC calibration

The three RC cal runs (RCCAL_START 0x55 = start, 0x15 = stop), the DONE
polls, and the BCAP/SCAP values read back afterwards.

In every trace, the first poll of run 1 sees DONE = 0x2 left over from
before, so run 1 is stopped at once. What differs is when the stop is
written:

  trace    driver                               run 1 stop  stop->start  BCAP  SCAP
  wl       wl 6.30.223.271                         43 us       118 us      8     8
  b43      b43 v7.0                                90 us       231 us      8     0
  rccal1   b43, udelay(35) before run 1's stop     44 us       234 us      8     7
  rccal2   same module as rccal1                   44 us       234 us      9     7
  rccal3   b43 with this patch (wl's delays)       48 us       117 us      9     8
  rccal4   same module as rccal3                   44 us       116 us      8     8

Other b43 traces (not included) stopped run 1 after 84-208 us and read
SCAP 0 or 0x1f.
BCAP varies between 8 and 9 from run to run with the same module.
