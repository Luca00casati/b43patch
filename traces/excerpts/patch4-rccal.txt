Patch 4/5: b43: N-PHY: wait for the first 2057 RC calibration run

The three RC cal runs (RCCAL_START 0x55 = start, 0x15 = stop) and the
SCAP value read back afterwards.
wl reads 8; b43 without the fix reads 0; rssi2 (b43 with the fix) reads 8.

NOTE: wl also polls DONE right after starting the first run and stops it
at once (55.752070 -> 55.752114), so the wait added by the patch is not
what wl does; it only brings b43's SCAP to wl's value.
