Patch 3/5: b43: N-PHY: fix rev3+ RSSI calibration

VCM search on radio 2057 (NB_MASTER_COREx, VCM in bits 2:0).
Each core sweeps VCM 0..7 (0x48..0x4f), then writes the selected one.
wl selects 3 on both cores (0x4b). b43 without the fix writes 0x48 (VCM 0,
the loop counter 8 truncated to 3 bits). rssi2 (b43 with the fix) selects
3 like wl. Only the NB_MASTER writes are shown; the RSSI reads between
them are left out.
